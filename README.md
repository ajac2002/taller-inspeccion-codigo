# Taller de inspeccion de codigo

Proyecto Java analizado con PMD para el taller de Ingenieria de Software II.

## Contenido

- `src`: codigo fuente corregido.
- `my_ruleset.xml`: reglas utilizadas en la inspeccion.
- `pom.xml`: configuracion de Java 21, Maven y PMD.
- `Informes_PMD`: informe inicial con 31 infracciones e informe final con 0 infracciones, en HTML y XML.
- `Evidencias`: capturas del proceso.
- `Reporte_Taller_Inspeccion_Codigo.pdf`: reporte final del taller.

## Verificacion

Para generar nuevamente el informe se puede ejecutar PMD con Maven. El proyecto fue compilado con JDK 21 y la verificacion final termino correctamente.
